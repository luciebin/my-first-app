# Let's Meet Offline

Jednoduchá webová aplikace vytvořená v Reactu jako závěrečný projekt během kurzu CodersLab.

Cílem aplikace je inspirovat uživatele k osobnímu setkávání mimo online svět – nabízí nápady na offline aktivity, které pomáhají budovat skutečné vztahy.

## 🌐 Live demo

➡️ [letsmeetoffline.com](https://letsmeetoffline.com/)

## 🔧 Použité technologie

- React
- JavaScript (ES6+)
- HTML, CSS
- Git & GitHub

## 🧠 Co jsem se naučila

- Práce s komponentami a props v Reactu
- Správa stavu pomocí `useState`
- Základy práce s Git verzováním
- Strukturování aplikace a psaní přehledného kódu
- Samostatné vedení menšího projektu od nápadu po realizaci
